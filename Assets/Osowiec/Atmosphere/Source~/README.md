# Звук «Осовца»

В банке 89 мастер-файла PCM 24 бита / 48 кГц. Сорок звуков сапог записаны в пяти вариантах покрытия по восемь дублей: сухой пол штаба, мокрый настил, грязь, вода и кирпич. Дубли отредактированы из полевых записей с отдельным слоем одежды. Авторы и лицензии лежат в `Assets/StreamingAssets/Osowiec Field Foley Credits.txt`, исходные записи — в `StepRecordings/`. Наружная и внутренняя атмосферы стереофонические.

Из этой папки:

```
python render_audio.py
python make_mask_cues.py
python verify_audio.py
```

Для генерации нужны Python 3, NumPy, SciPy и SoundFile. Мастер-файлы находятся в `Resources/OsowiecSound`. `render_audio.py` в конце вызывает `render_field_foley.py` для записанных шагов и новой партитуры. `verify_audio.py` сверяет формат, пики, постоянное смещение, швы петель, корреляцию дублей и длину синхронных стемов.

Мелодия граммофона открывается фразой ля–до–фа, ми–ре–до. Та же фраза переходит в приглушённую медь в поле. Файлы `FieldBows`, `FieldBrass`, `FieldIron`, `FieldAir` содержат отдельные партии смычковых, меди, металла и воздушной фактуры. Каждая длится 24,48 секунды, шестнадцать тактов 3/4. Планирование и FPS делят один DSP-транспорт. Входы слоёв приходятся на границу такта; близкое событие быстро приглушает музыку. Шум повозки, костюмы классов и сигналы имеют свои источники. Запуск с `-osowiec-audio-trace` пишет в лог игровое время, исполнителя, стопу, поверхность и выбранный клип. Метки score указывают положение внутри партитуры.

В штабе послушайте вальс возле граммофона и у противоположной стены, затем откройте карту. В миссии проведите одного бойца по настилу, грунту и кирпичу, проверяя совпадение шага с поверхностью. Под сводом дождь снаружи глушится, дыхание в маске меняет перспективу, дверь звучит со стороны взаимодействия. Для проверки отдельных шин в Unity откройте `FieldMix.mixer`. В сборке общая громкость эффектов и музыки регулируется из меню. Запись с клиентского окна и звуком конкретного процесса можно проверить по файлу рядом с видео.
